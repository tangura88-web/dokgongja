독공자 로고 파일
================================================

[ 심벌마크의 뜻 ]

한글 '공'(공부의 공)을 단순화한 일출 형태입니다. 위에서 아래로 읽습니다.

  오렌지 반원 — 목표    떠오르는 태양. 스스로 세운 목표와 거기에 닿겠다는 의지.
  검은 가로선 — 규율    흔들리지 않는 학습 원칙. 시간·생활·학습 관리.
  아래 원     — 몰입    방해 없이 자기 공부에 잠긴 상태. 닫힌 원은 집중과 지속.

  목표 → 규율 → 몰입 → 성취


[ 폴더 구성 ]

01_심벌마크   얼굴 없는 마크 단독. 앱 아이콘, 파비콘, 명함, 굿즈.
02_로고타입   '독공자' 글자. 이름을 읽혀야 하는 자리.
03_조합형     심벌 + 로고타입 + 태그라인. 간판, 표지, 소개자료.


[ 어떤 파일을 쓰나 ]

흰 바탕 위                  → 기본 파일
어두운 바탕 위              → ..._반전 (먹이 흰색으로 바뀝니다. 태양은 그대로)
앱 아이콘                   → 독공자_앱아이콘 / _어두운형
가로로 긴 자리(간판, 헤더)  → 독공자_가로조합형
정사각 자리(프로필, 표지)   → 독공자_세로조합형

SVG = 원본. 크기를 키워도 깨지지 않습니다. 인쇄·간판은 반드시 SVG를 주세요.
PNG = 1024×1024. 발표자료, 카톡, 문서에 급히 붙일 때.


[ 최소 크기 ]

심벌      24px / 8mm
로고타입  가로 90px / 25mm
조합형    가로 150px / 40mm


[ 하지 말아야 할 것 ]

· 태양을 가로선 아래로 내리거나 원을 위로 올리지 않습니다. 의미가 뒤집힙니다.
· 반원을 먹이나 다른 색으로 칠하지 않습니다. 목표를 지우는 것과 같습니다.
· 아래 원의 속을 메우지 않습니다. 비어 있어야 몰입이 읽힙니다.
· 가로세로 비율을 따로 늘이지 않습니다. 확대·축소는 비율 그대로.
· 그림자, 그라데이션, 외곽선, 기울임, 회전을 넣지 않습니다.
· 로고타입을 다른 서체로 다시 쓰지 않습니다. 이 폴더의 파일만 씁니다.

[ 서체 ]

로고타입은 어떤 서체에서도 나오지 않는 전용 자형입니다.
시안 이미지를 벡터로 추출해 만든 것이라, 서체를 설치해 '독공자'라고 입력해도
이 모양은 나오지 않습니다. 반드시 이 폴더의 파일을 쓰세요.
태그라인 '단 하나의 관리'만 Gothic A1(SIL 오픈폰트 라이선스)을 씁니다.
